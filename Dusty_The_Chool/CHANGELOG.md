# Change Log

All notable changes to the "dusty-the-chool" extension will be documented in this file.

## [0.1.0] - Initial Release

- **Broom Character in Sidebar**: Pixel-art animated Kerala chool (broom) with expressive eyes, dustpan (Murram), live state badges, CRT scanline overlay, and speech bubble.
- **Safe Error Sweeping**: Multi-frame gutter animation that sweeps disposable syntax errors (stray semicolons, dangling brackets) into the dustpan.
- **Hunger & Mischief Engine**: Randomized timer detecting lack of syntax errors, issuing hunger warnings and playfully deleting working code if ignored.
- **Rage & Crashout Apocalypse**: Real-time rage meter reaching 100% when provoked, triggering apocalyptic strobe themes and vengeful code sweeping.
- **English Kerala Meme Roasts**: 60+ savage roast templates referencing viral Kerala internet memes (*Aaraattu Annan, Vazha, KSRTC Swift, KSEB load shedding, Moral policing uncles, Food vloggers, PSC coaching, Santhosh Pandit*).
- **Ollama 3B Integration**: Optional local LLM support for generating contextual Kerala meme roasts.
- **Procedural Web Audio**: Zero-asset 8-bit sound synthesizer with support for custom drop-in audio files.
- **CodeLens & Status Bar**: Native VS Code integration with interactive status bar and inline error sweep lenses.
