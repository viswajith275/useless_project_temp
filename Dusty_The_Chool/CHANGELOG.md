# Change Log

All notable changes to the "dusty-the-chool" extension will be documented in this file.

## [0.1.0] - Initial Release

- **Broom Character in Sidebar**: Pixel-art animated Kerala chool (broom) with expressive eyes, dustpan (Murram), live state badges, CRT scanline overlay, and speech bubble.
- **Safe Error Sweeping**: Multi-frame gutter animation that sweeps disposable syntax errors (stray semicolons, dangling brackets) into the dustpan.
- **Multi-Tier Type Error Harvester**: Classifies type mismatches (TS2322/TS2345), missing properties (TS2339), implicit any (TS7006), argument count errors, and compounding line clusters via 3-tier hybrid roaster.
- **Hunger & Mischief Engine**: Randomized timer detecting lack of syntax errors, issuing hunger warnings and mischievously deleting working code if ignored. Preserves hunger across file saves (`Cmd+S`) with in-character starvation taunts.
- **Rage & Crashout Apocalypse**: Real-time rage meter reaching 100% when provoked—or when spamming the "Clean Dustpan" button 3+ times on an empty dustpan—triggering apocalyptic strobe themes, vengeful code sweeping, and displaying the explicit crashout reason in the dialogue.
- **English & Manglish Kerala Meme Roasts**: 100+ savage roast templates referencing viral Kerala internet memes (*Aaraattu Annan, Vazha, KSRTC Swift, KSEB load shedding, Moral policing uncles, Food vloggers, PSC coaching, Santhosh Pandit*).
- **Instant Language Switcher**: Switch dynamically between English and Manglish (`Cmd+Alt+D L`) across the entire extension (UI buttons, state badges, status bar, and LLM prompt system).
- **Local LLM (Ollama) Integration**: Optional local LLM support via Ollama (recommended: `llama3.2:3b`) for generating contextual Kerala meme roasts, featuring ChatML stop-token stripping and formulaic review prefix cleaning.
- **Procedural Web Audio**: Zero-asset 8-bit sound synthesizer with support for custom drop-in audio files.
- **CodeLens & Status Bar**: Native VS Code integration with interactive status bar and inline error sweep lenses.
