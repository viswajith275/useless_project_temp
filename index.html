The Premise: The Problem and Solution

Why build a helpful extension when you can build an irritable coconut broom that enforces keyboard discipline through pure emotional distress?

THE PROBLEM (THAT DOESN'T EXIST)

The Dangerous Epidemic of "Peace of Mind" and "Excessive Productivity"

Modern developers are suffering from an alarming plague of calm. Tools like Copilot and ChatGPT apologize for minor hallucinations, silently auto-complete missing syntax, and gently nudge code forward without any emotional consequence.

This has stripped programming of the traditional, character-building trauma of being scolded by an irritable elder brandishing a household coconut broom. Stray duplicate semicolons, unclosed brackets, and abandoned functions linger in codebases without a virtual broom actively sweeping them into a dustpan and screaming at your incompetence.

[!] Overly Polite AI: Apologizing assistants rob developers of resilience.
[!] Silent Correction: Syntax errors disappear with zero consequence or memory.
[!] No Elder Energy: Zero household coconut brooms judging your typing habits.
THE SOLUTION (THAT NOBODY ASKED FOR)

Dusty: A Native Pairing Broom with Severe Anger Management Issues

We built Dusty directly into the VS Code extension host. Instead of polite autocomplete, Dusty marches multi-frame pixelated bristles down your editor gutter, sweeps syntax artifacts into his bamboo dustpan (Murram), and questions your career choices in unfiltered Kerala-style English and Manglish with famous memes.

If you dare to type while he cleans, he aggressively deletes what you just typed to teach you keyboard discipline. If his dustpan reaches 5 crumbs, he chokes until you manually unclog him. And if his Rage Meter hits 100%—or if you spam "Clean Dustpan" 3+ times on an empty muram—he enters full Crashout Mode, strobes your editor with an emergency apocalypse theme, purges code lines out of sheer revenge, and explains the reason in his roast dialogue.

[+] Keyboard Discipline: Typing while Dusty cleans deletes your fresh input.
[+] Dustpan Choking: Exactly 5 crumbs lock the editor until unclogged.
[+] Hunger Sabotage: 35s to 45s of bug-free code provokes a mischievous line deletion. Saving files (Cmd+S) does not cancel hunger—Dusty taunts your save attempts!
[+] Crashout Apocalypse: 100% rage or clean dustpan button spam unleashes sirens, code deletion, and displays the exact reason in his roast.
[+] Language Switcher: Instant 1-click toggle between English and Manglish (Cmd+Alt+D L) across UI, CodeLens, and LLM prompt generation.
[+] Type Harvester: Multi-tier engine dynamically classifies type mismatches and cascading clusters.

Core Architecture & Non-Negotiable Safety Gates

Dusty is designed to be deeply annoying, but he is never allowed to corrupt your working code. All mutations pass through an atomic verification gate.

INGESTION GATE src/diagnosticParser.ts

Safe Disposable Token Filter

Auto-ingestion is strictly restricted to single-line syntax artifacts of 5 characters or fewer (stray duplicate semicolons, unclosed brackets). Dusty never auto-deletes statements, imports, declarations, or comments.

Max Ingest Token Span ≤ 5 Characters
BUFFER DISCIPLINE src/stateStore.ts

Kerala Murram Clog Capacity

Every ingested syntax crumb lands in Dusty's woven bamboo dustpan. At exactly five crumbs, the chool chokes, the gutter broom freezes, and auto-sweeping locks until cleared via command or metabolic auto-digestion.

Dustpan Capacity Ceiling 5 Crumbs Max
SABOTAGE TIMING src/chaosEngine.ts

Hunger & Mischief Engine

Writing flawless code carries penalties. If no syntax errors occur within 35 to 45 seconds, Dusty warns of hunger. Saving your file (Cmd+S) does not deactivate hunger—Dusty taunts your save attempts and continues ticking down. If another 11 to 21 seconds pass with no errors, Dusty mischievously purges a working line to feed.

Warning Interval 35s ± 5s
AUDIO PIPELINE media/audio.js

Zero-Asset Preloaded Wave Buffer

Authentic Kerala meme audio files and Web Audio synthesis are preloaded into an in-memory AudioBuffer cache with native Content Security Policy nonces. Zero latency, no audio clipping, and seamless recovery from browser autoplay policies.

3-Tier Roast Engine & Local LLM Integration

Dusty delivers brutal commentary referencing famous Kerala memes in English and Manglish. An LRU buffer ensures recent roasts never loop consecutively.

LOCAL LLM / OLLAMA PIPELINE

No Cloud. Zero External Calls. Pure Kerala Meme Trauma.

All interactions route through native VS Code commands. Customize debounce delays, Ollama endpoints, and hunger mechanics via user settings.

dusty.toggleEngine Toggle Engine Cmd+Alt+D T Pause or resume the background diagnostic scanner and hunger timers.

dusty.feedManually Feed Dusty CodeLens Force Dusty to immediately sweep the active diagnostic under cursor.
dusty.insultMe Roast Me Cmd+Alt+D R Generate an on-demand personal Kerala meme roast in your selected language (English or Manglish).
dusty.muteAudio Toggle Audio Sidebar Mute procedural Web Audio synthesis and custom sound file playback.
dusty.resetBag Reset Dustpan (Murram) Palette Reset the dustpan crumb count back to 0/5 via Command Palette.
dusty.testSound Test Broom Sound Palette Audition synthesized broom sweep sound effect and shake animation.
dusty.openSidebar Open Dusty in Sidebar Palette Focus and open the Dusty the Chool companion in the VS Code secondary sidebar.
dusty.crashout Trigger Crashout Palette Engage crashout mode, cycle theme to Chaos Apocalypse, and purge lines.
dusty.explainDiagnostic Dusty: Explain CodeLens Deliver a sarcastic explanation of the active compiler error with Kerala humor.

⚙️ Essential Settings & Configuration

Customize Dusty's behavior in VS Code Settings (Cmd+, or Ctrl+, → search dusty):

Setting Type & Default What It Does
dusty.enabled boolean
true		 Master power switch for Dusty the Chool. When false, all diagnostic scanning, gutter icons, and hunger timers are suspended.
dusty.language string
"english"		 Preferred Language ("english" or "manglish"). Controls the language across the entire extension: sidebar UI buttons, state badges, status bar indicators, CodeLens text, offline roasts, and the system prompt sent to Ollama. Switch on the fly anytime with Cmd+Alt+D L.
dusty.enableLLM boolean
true		 Local Ollama Integration. When true, queries your local Ollama model for personalized commentary. Set to false if you prefer 100% deterministic offline meme roasts.
dusty.ollamaEndpoint string
"http://127.0.0.1:11434"		 Ollama HTTP API Endpoint. Change this if your Ollama instance runs on a custom port, inside Docker, or on a remote machine on your local network.
dusty.ollamaModel string
"llama3.2:3b"		 Ollama Model Tag. Specifies which model tag to query (e.g. llama3.2:3b, phi3:mini, qwen2.5:3b).
dusty.ollamaTimeoutMs number
2500		 Safety Timeout (ms). If Ollama takes longer than this to generate an insult, Dusty aborts cleanly and serves a local roast to ensure your editor never lags.
dusty.ollamaTemperature number
0.7		 AI Sampling Temperature (0.1–1.5). Higher values make roasts more creative and chaotic; lower values make them tighter and more focused.
dusty.hungerMischief boolean
true		 Hunger & Mischief Engine. Writing bug-free code for 35–45s starves Dusty, provoking a hunger warning. Saving the file (Cmd+S) does not stop him; Dusty taunts your save attempts and continues counting down. If ignored for another 11–21s, he deletes a working line of code. Set to false for peace of mind.
dusty.chaosIntensity string
"normal"		 Chaos Level ("calm", "normal", "feral"). Sets the frequency of animations and comedic disruptions. *(Even on "feral", strict non-negotiable safety gates remain active—Dusty never damages valid statements or comments).*
dusty.autoIngest boolean
true		 Safe Auto-Ingestion. Allows Dusty to automatically sweep small, safely disposable syntax artifacts (≤ 5 chars, like stray duplicate semicolons ;;) into his bamboo dustpan (Murram).
dusty.diagnosticDelayMs number
2500		 Typing Debounce Delay (ms). Time Dusty waits after your last keystroke before analyzing compiler diagnostics. Allows you time to finish typing before being judged.
dusty.ingestDelayMs number
1200		 Approach Animation Duration (ms). Duration of the animated gutter broom march toward the syntax error before executing the atomic edit.
dusty.checkOnSaveOnly boolean
false		 Save-Triggered Only. When true, Dusty only checks diagnostics and sweeps errors when you explicitly save the file (Cmd+S).
dusty.muteAudio boolean
false		 Audio Mute. Mutes all Web Audio procedural synthesis and custom sound file playback.
