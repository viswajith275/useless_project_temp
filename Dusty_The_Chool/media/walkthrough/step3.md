### Feeding Syntax Errors

Dusty hunts for syntax errors in your active editor.

Try writing a stray disposable syntax typo:
```typescript
const message = "Hello world";; // Note the extra semicolon
```

Dusty will target the line, animate pixel-art broom bristles down your gutter, and sweep the token away while lecturing you on basic keyboard discipline. Dusty also harvests type mismatches, missing properties, and compounding error clusters with a 3-tier hybrid roasting engine!
